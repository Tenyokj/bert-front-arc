`0xea1db9920001148186b76cc2504a73ca3da6b7697717d2aee9c6b4ffd9376dff`.
The official archive SHA-256 was checked, and the extracted Anvil binary matched
the executable. Actual native USDC at `0x3600000000000000000000000000000000000000`
was used; no replacement token, balance-storage patch or issuer bypass.

Fresh production Transparent proxies use real RolesRegistry, IdeaRegistry,
VotingSystem, FundingPool, GrantManager, Reputation, VoterProgression and
PoPVerifier wiring. Local signed credentials are test access, not personhood.
The native token blocks public development account #1 at this pinned state;
the harness deliberately skips it and verifies that it remains blocked.

Native USDC also pays gas. Assertions compare 18-decimal native balances and add
back the recipient's own receipt gas cost before comparing transfers; the
six-decimal ERC-20 view is checked separately. A raw before/after ERC-20 wallet
balance is not an exact payout assertion when that wallet also paid gas.

The original public pool address still holds exactly 1,140 USDC **on the fork**.
This run uses fresh local proxies; it does not replace the separate
[populated-proxy upgrade rehearsal](V2.4-REVENUE-SECURITY-REVIEW.md) or a fresh
public custody/authority preflight.

## Reproduction

Use a disposable Arc Anvil, not generic EDR, and a verified official executable.
Start only if port 19548 is free; never reset another developer's node:

```bash
"$ARC_ANVIL" --network arc --fork-url https://arc-testnet.drpc.org \
  --fork-block-number 73753950 --chain-id 31337 \
  --host 127.0.0.1 --port 19548 --silent
```

In the core checkout with ordinary artifacts compiled:

```bash
node scripts/local/accept-v2-4-native-grants.mjs
```

The script does not load dotenv, request a private key or accept a public RPC
override. It checks the local chain, Arc execution mode, fork number/hash and
public development accounts before deploying. It writes
`/private/tmp/bert-v24-native-grants.json`; `REVENUE_NATIVE_REPORT` changes only
the evidence output path. Report addresses/transactions are local fixtures,
not public deployment evidence. Local time jumps do not satisfy public deadlines.

Stop only the node/process started for this run after downstream indexer checks.
Do not use these public development accounts for real assets.

## Earlier Native Arc/Graph Attempt: Partial, Not Accepted

The real 0.40 Graph Node/Postgres run matches 38 revenue logs and the complete
1.08-USDC financial totals, hydrates the immutable beneficiary and preserves
entities after restart. [Partial report](https://github.com/Tenyokj/bert-core-arc/blob/arc-usdc-migration/docs/security-reports/v2.4-graph-node-partial-2026-11-24.json).
Controlled reorg and clean replay are **not passed**. An initial two-block reorg
was too close to the indexing start for Graph's default 250-block threshold.
After padding the local history, earlier calls on Arc Anvil return
`missing bytecode for code hash`; repeating with Graph 0.45 does not fix that RPC
response. [Fail-closed preflight evidence](https://github.com/Tenyokj/bert-core-arc/blob/arc-usdc-migration/docs/security-reports/v2.4-graph-node-blocker-2026-11-24.json).

The failed probe targets the first local proposal block, not public contracts.
This is an execution-provider/history limitation, not proof of a contract exploit;
the successful current-state financial receipts are recorded separately.
Do not bypass historical calls or invent indexed values to obtain a passing run.
Use a fresh archive-capable fixture or isolate the Graph acceptance on a separate
disposable chain, retaining this native-asset evidence as its own test layer.
Frontend reproduction: `subgraph/NATIVE-REVENUE-ACCEPTANCE.md`.

The remaining Graph gate was subsequently closed on a separate fresh MockUSDC
chain with production modules and real Graph Node/Postgres: exact 38-log
agreement, restart, reorg and clean replay pass. See
[Graph acceptance](V2.4-GRAPH-ACCEPTANCE.md). This does not retroactively turn the
failed Arc-fork historical path into a passing test.
