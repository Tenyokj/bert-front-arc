## Scope

The first rejected proof gets a fixed correction deadline: rejection community
time + 48-hour cooldown + configured proof duration. Reopening cannot extend it.
Permissionless expiry also handles abandoned correction cooldowns. Failure refunds
only unpaid execution capital; prior payments, validator rewards, 20/40/40 splits,
self-review exclusion and per-tranche Admin quorum are unchanged.

Existing immutable V3.0/V3.1/V3.2.0 Communities are **not upgraded**. In particular,
historical Managers retain the correction liveness defect. Use the new Factory for
corrected pilots. No automatic migration of memberships, votes or funds occurs.
