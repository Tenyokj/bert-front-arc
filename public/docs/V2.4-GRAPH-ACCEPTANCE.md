## Observed Results

The fresh chain uses MockUSDC and ordinary production proxies/modules, including
the real GrantManager and local signed PoP credentials. All four grant outcomes
pass: full 20/40/40, cancellation after 0/20/60%, exact refunds and earned fees.
169 fixture receipts confirm deployment, setup and execution; the Graph reorg
adds a separately recorded temporary policy transaction.

- All **38 canonical revenue event IDs** match RPC exactly once.
- Four round snapshots agree with contract outcomes: 0 / 0.12 / 0.36 / 0.6 USDC
  accrued, totaling **1.08 USDC** collected/paid, zero pending.
- Treasury discovery hydrates its real immutable beneficiary/share getters and
  starts the dynamic template. The payee is a disposable local account.
- Restarting Graph Node preserves all queried revenue entities without duplication.
- A controlled two-block reorg removes the orphan policy event, clears its pending
  settings and restores the baseline financial entities. Indexed block hash must
  match canonical RPC; `Synced` alone is not accepted.
- Deleting only the lab's Postgres/IPFS volumes and rebuilding a clean deployment
  reproduces the same canonical revenue entities after the reorg.

## Separate Execution Layers

This test uses **MockUSDC, fresh Ethereum execution, chain 31337**, not native Arc.
The [native Arc financial run](V2.4-NATIVE-ACCEPTANCE.md) passed separately with
160 receipts and real native USDC. Browser acceptance separately uses the local
EIP-1193 test wallet. Together they close the agreed bounded local matrix; none
is an independent audit, public pilot or actual MetaMask/mobile-wallet test.

The old Arc-fork historical-bytecode failure remains a documented limitation of
that fixture. It was not fixed or bypassed: this Graph test starts a new non-fork
chain and labels the asset/execution explicitly. Historical RPC is checked before
Docker reset/deployment. Start block zero also avoids testing a two-block reorg
inside the earlier fixture's earliest-block + reorg-threshold restriction.

## Reproduction

With the verified Arc Anvil executable, ordinary core artifacts and dependencies,
start only if port 19549 is free:

```bash
"$ARC_ANVIL" --network ethereum --chain-id 31337 \
  --host 127.0.0.1 --port 19549 --silent
```

From core, then from the sibling frontend (Docker Desktop running):

```bash
# core
REVENUE_GRAPH_FIXTURE=true node scripts/local/accept-v2-4-native-grants.mjs
# frontend
REVENUE_GRAPH_FIXTURE=true REVENUE_GRAPH_RESET_LOCAL=true \
  node subgraph/scripts/accept-revenue-graph-node.mjs
```

The explicit MockUSDC mode uses only loopback port 19549, requires a fresh
non-fork Anvil chain and writes separate fixture/Graph JSON files in `/private/tmp`.
Without the flag, the native Arc path and its separate output/guards remain.
The Graph runner resets only Docker project `bert-v24-native` and its disposable
volumes; never place shared/personal data there. Normal manifests, environment
files, public start blocks and deployment records are not rewritten.

After preserving evidence, run from frontend:

```bash
docker compose -p bert-v24-native -f subgraph/docker-compose.revenue.yml down -v
```

Stop only the Anvil process owned by this run. See the
[acceptance matrix](V2.4-E2E-ACCEPTANCE.md) and
[release sequence](V2.4-RELEASE-CONFIGURATION.md) for remaining public gates.
